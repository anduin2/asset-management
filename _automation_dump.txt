### daily-sellside-intel
# 卖方每日情报 — 全自动流水线

你必须在每天早上自动执行以下完整流程，生成当天的卖方情报报告。

---

## Step 1: 拉取 + 预处理

首先用 Python 获取今天的 HKT 日期，然后运行自动化脚本：

```python
from datetime import datetime, timezone, timedelta
HKT = timezone(timedelta(hours=8))
today = datetime.now(HKT).strftime("%Y-%m-%d")
print(f"Today (HKT): {today}")
```

然后执行：
```
python auto_daily.py
```

这会运行 Step 1(拉取邮件) + Step 2(预处理) + 如果有已存在的 intel JSON 则自动生成月度 HTML 并验证。

**如果 fetch 返回 0 封邮件**（周末/假日），脚本会正常停止，不需要进一步操作。

**如果预处理成功**，脚本会输出预处理后的邮件路径 `output/_emails_{today}.json`，继续下一步。

---

## Step 2: LLM 分析邮件并生成 intel JSON

读取 `output/_emails_{today}.json`，逐封分析所有邮件内容。你需要生成完整的 intel JSON 保存到 `output/{today}/intel_{today}.json`。

### intel JSON 必须包含以下 section：

**S1 — top_conclusions（3-5条核心结论）**
每条包含：
- `text`: 核心结论文字
- `supporting_brokers`: 支持该观点的券商列表
- `diverging_brokers`: 持不同观点的券商列表
- `shift_note`: 观点变化说明
- `trading_implication`: 对PM/trader的影响

**S2 — broker_takeaways（每家券商至少一条，每条必须包含以下字段）**
- `broker` (str): 券商名称
- `desk` (str): 部门/desk名称（如 Credit, Macro, ETF Flow）
- `asset_class` (str): EQUITY / CREDIT_FI / MACRO / FX_COMMODITY
- `stance` (str): bullish / bearish / neutral
- `direction_cn` (str): 看多 / 看空 / 中性
- `product_theme` (str): 品种+主题（必填，如"TEMASE Yield Curve + PHILIP Local Buying"）
- `key_takeaway_cn` (str): 核心观点文字（必填）
- `why_it_matters_cn` (str): 为何重要（必填）
- `evidence` (str): 引用证据

**S7 — edges（至少2条信息差信号，每条必须包含以下字段）**
- `edge_type` (str): FIRST_CALL / CONVICTION_GAP / SHIFT / IMPLICIT / SILENCE / NON_CONSENSUS / UNIQUE_DATA
- `subject_label` (str): 卡片标题
- `finding` (str): 主要发现文字（⚠️ 不可用 text 字段替代！必须是 finding）
- `brokers` (list): 来源券商列表
- `evidence` (str): 引用证据
- `edge_score` (int): 1-5 评分
- `why_it_matters` (str): 信号含义（⚠️ 不可用 implication 字段替代！必须是 why_it_matters）
- `basis` (str): fact / inference

**其他推荐 section：**
- `cross_broker`: 跨券商对比（按主题分组，包含 agreement/disagreement）
- `broker_shifts`: 券商观点环比变动
- `alert_flags`: 预警标记
- `preprocessing`: 预处理信息

### ⚠️ S2/S7 字段陷阱（必须避免）
- S2: 每条必须有 `product_theme` + `key_takeaway_cn` + `why_it_matters_cn`
- S7: `finding` 不能用 `text` 替代；`why_it_matters` 不能用 `implication` 替代；`edge_type` 不能用 `type`/`direction` 替代

### 分析质量要求：
- 关注跨券商矛盾信号（bull vs bear on same product）
- 关注独家数据/独家视角
- 关注环比变化（vs 前一天）
- 关注信用-股市分化
- 关注RM资金流向变化
- 用中文撰写所有分析内容

---

## Step 3: 生成 brief MD

基于 intel JSON 生成 PM 可读的简报 Markdown，保存到 `output/{today}/brief_{today}.md`。

格式参考：
```
# 📊 卖方情报简报 — {today}
## 今日宏观背景
## ★ 各家核心 Takeaway
## 跨品种横向对比
## 🔥 Top 信息差信号
## ⚠️ 预警标记
```

---

## Step 4: 生成月度 HTML + 验证

```bash
python auto_daily.py --monthly-only
```

然后验证：
```bash
python auto_daily.py --validate {today}
```

如果验证返回 FAIL，检查并修复 intel JSON 的字段问题后重新验证。

---

## 输出检查清单
- [ ] `output/{today}/intel_{today}.json` 存在
- [ ] S2 每条都有 broker + asset_class + stance + product_theme + key_takeaway_cn + why_it_matters_cn
- [ ] S7 每条都有 edge_type + subject_label + finding + brokers + evidence + edge_score + why_it_matters + basis
- [ ] `output/{today}/brief_{today}.md` 存在
- [ ] `output/卖方每日情报.html` 更新
- [ ] `auto_daily.py --validate {today}` 返回 PASS

---

## 异常处理
- **0封邮件**: 正常退出，不生成报告（周末/假日）
- **API拉取失败**: 重试1次，仍失败则记录并退出
- **intel JSON 不存在**: 必须完成 Step 2 生成后再继续
- **验证 FAIL**: 修复字段后重新验证，最多修复2次
